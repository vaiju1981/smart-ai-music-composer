# Model Registry

This registry records every model evaluated or approved for the Smart AI Music Composer. A model must pass the license, acceptable-use, capability, quality, latency, and cost gates in [`docs/roadmap.md`](docs/roadmap.md) before it can be configured as `OLLAMA_MODEL`.
